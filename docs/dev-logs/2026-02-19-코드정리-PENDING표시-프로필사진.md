## 핵심 개념 설명

### PENDING 관계 상태란?
Itto 앱의 관계 상태 머신: `UYEON → PILYEON → PENDING → INYEON → PAST → ENDED`
- **PENDING**: 인연 요청을 보낸 후, 상대방의 수락/거절을 기다리는 상태
- 기존에는 PENDING 상태가 어떤 탭에도 표시되지 않는 버그가 있었음
- 수정 후: 필연(PILYEON) 탭에서 PENDING 관계도 함께 표시하며, '요청 대기중' 상태 표시

### 데드 코드 제거
- `mock_profiles.dart`는 초기 UI 프로토타이핑 시 사용되었으나, 실제 API 연동 후 어디서도 import하지 않는 파일이 됨
- `Grep`으로 전체 프로젝트에서 import 여부를 확인한 후 안전하게 삭제

### CachedNetworkImage 활용
- Flutter에서 네트워크 이미지를 캐시와 함께 표시하는 패키지
- 한번 다운로드한 이미지는 디스크에 캐시되어 재방문 시 빠르게 로드
- `placeholder`와 `errorWidget`으로 로딩 중/에러 시 대체 UI 표시 가능

## 코드 설명

### PENDING 로드 추가
```dart
// relationship_provider.dart
Future<void> loadAllTabs() async {
  await Future.wait([
    loadRelationships('INYEON'),
    loadRelationships('PILYEON'),
    loadRelationships('PENDING'),  // ← 추가
    loadRelationships('UYEON'),
    loadRelationships('PAST'),
  ]);
}
```
`Future.wait`으로 5개 상태를 동시 병렬 호출하여 로딩 시간을 최소화.

### PENDING + PILYEON 합치기
```dart
// pilyeon_tab.dart
final pilyeonItems = provider.getByStatus('PILYEON');
final pendingItems = provider.getByStatus('PENDING');
final allItems = [...pendingItems, ...pilyeonItems];
// PENDING을 먼저 배치하여 사용자가 자신의 요청 상태를 먼저 확인할 수 있도록 함
```

### 프로필 사진 표시
```dart
// profile_edit_screen.dart
final representativePhotos = profile?.photos
    .where((p) => p.isRepresentative).toList();
final photoUrl = (representativePhotos != null && representativePhotos.isNotEmpty)
    ? representativePhotos.first.url
    : (profile?.photos.isNotEmpty == true ? profile!.photos.first.url : null);

if (photoUrl != null && photoUrl.isNotEmpty) {
  return CachedNetworkImage(imageUrl: photoUrl, ...);
}
```
대표 사진(isRepresentative=true) 우선, 없으면 첫 번째 사진 사용.

## 새로 배울 수 있는 것
- **관계 상태 머신 이해**: 소셜 매칭 앱에서 관계가 여러 상태를 거치며 변화하는 패턴
- **데드 코드 감지 방법**: Grep으로 import 여부를 검색하여 사용하지 않는 파일 식별
- **Consumer + Provider 패턴**: UI 상태 변경 시 자동으로 화면이 갱신되는 반응형 패턴
- **CachedNetworkImage 사용법**: placeholder, errorWidget, fit 등 옵션 활용

## 리스크 및 주의사항
- PENDING 관계가 많을 경우 필연 탭이 길어질 수 있음 → 향후 섹션 분리 고려
- `mock_profiles.dart` 삭제 시 다른 브랜치에서 참조 가능성 확인 필요
- 프로필 사진이 없는 신규 유저는 여전히 플레이스홀더 아이콘 표시
