## 핵심 개념 설명

### url_launcher
외부 앱이나 브라우저를 열어주는 Flutter 플러그인입니다.
- `mailto:` URI로 이메일 앱 열기
- `https://` URI로 브라우저/스토어 열기
- `LaunchMode.externalApplication`은 항상 외부 앱에서 열도록 강제

### package_info_plus
앱의 메타 정보(버전, 빌드 번호, 패키지명)를 조회하는 플러그인입니다.
- `PackageInfo.fromPlatform()`으로 현재 앱의 버전 정보를 가져옴
- `pubspec.yaml`의 `version: 1.0.0+1`에서 `1.0.0`은 version, `1`은 buildNumber

### share_plus
네이티브 공유 시트를 표시하는 Flutter 플러그인입니다.
- `SharePlus.instance.share(ShareParams(text: '...'))` 한 줄로 시스템 공유 UI 호출
- 카카오톡, 메시지, 이메일 등 설치된 앱으로 텍스트/링크를 공유

### 시맨틱 버전 비교 (Semantic Versioning)
```
1.2.3
│ │ └─ Patch: 버그 수정
│ └── Minor: 기능 추가 (하위 호환)
└─── Major: 호환성 깨지는 변경
```
- `_isVersionLowerThan('1.0.0', '1.1.0')` → true (업데이트 필요)
- `_isVersionLowerThan('2.0.0', '1.1.0')` → false (최신)
- 각 자릿수를 순서대로 비교하여 현재 버전이 최소 요구 버전보다 낮은지 판단

### 강제 업데이트 패턴
```
앱 시작 → 스플래시 → 서버에 최소 버전 질의 → 비교
   ↓ 낮으면: 업데이트 다이얼로그 (닫기 불가, barrierDismissible: false)
   ↓ 같거나 높으면: 정상 진행 (로그인 체크 → 홈/로그인)
```

## 코드 설명

### 1. 회원탈퇴 다이얼로그 (settings_screen.dart)
```dart
void _showWithdrawDialog(BuildContext context) {
  showDialog(
    context: context,
    builder: (ctx) => AlertDialog(
      title: const Text('회원탈퇴'),
      content: const Text('정말 탈퇴하시겠습니까?\n모든 데이터가 삭제되며 복구할 수 없습니다.'),
      actions: [
        TextButton(onPressed: () => Navigator.pop(ctx), child: const Text('취소')),
        TextButton(
          onPressed: () async {
            Navigator.pop(ctx);
            await context.read<AuthProvider>().withdraw();
            if (context.mounted) context.go('/login');
          },
          child: const Text('탈퇴', style: TextStyle(color: Colors.red)),
        ),
      ],
    ),
  );
}
```
- `showDialog`로 확인 다이얼로그를 표시
- "탈퇴" 클릭 시 다이얼로그를 닫고 → 서버 API 호출(withdraw) → 로그인 화면으로 이동
- `context.mounted` 체크: async 작업 후 위젯이 아직 살아있는지 확인 (메모리 누수 방지)

### 2. 강제 업데이트 체크 (splash_screen.dart)
```dart
Future<bool> _checkForceUpdate() async {
  try {
    final systemService = SystemService(apiClient);
    final versionInfo = await systemService.checkVersion();
    final packageInfo = await PackageInfo.fromPlatform();

    if (_isVersionLowerThan(packageInfo.version, versionInfo.minVersion)) {
      _showForceUpdateDialog(versionInfo.updateUrl);
      return true;
    }
  } catch (_) {
    // 실패 시 무시하고 진행
  }
  return false;
}
```
- `SystemService.checkVersion()`으로 서버에서 최소 요구 버전 조회
- `PackageInfo.fromPlatform()`으로 현재 앱 버전 조회
- 버전이 낮으면 `barrierDismissible: false` 다이얼로그로 업데이트 강제

## 새로 배울 수 있는 것
- **url_launcher**: 이메일, 전화, 웹 등 다양한 URI scheme을 열 수 있는 방법
- **package_info_plus**: 빌드 타임에 결정된 앱 메타데이터를 런타임에 조회하는 방법
- **share_plus**: 시스템 네이티브 공유 시트를 활용하는 방법
- **시맨틱 버전 비교**: 문자열 버전을 정수 배열로 변환하여 비교하는 알고리즘
- **barrierDismissible**: 다이얼로그 바깥 영역 터치로 닫기를 막는 옵션
- **isDestructive 패턴**: UI에서 위험한 동작을 시각적으로 구분하는 UX 패턴

## 리스크 및 주의사항
- **share_plus 플레이스토어 URL**: 현재 가짜 URL(`com.itto.app`) 사용 중. 실제 배포 시 올바른 패키지명으로 교체 필요
- **고객센터 이메일**: `support@hguitto.site`가 실제로 수신 가능한지 확인 필요
- **버전 체크 API**: 서버의 `/system/version` 엔드포인트가 인증 없이 접근 가능해야 함 (스플래시에서 호출되므로)
- **업데이트 다이얼로그**: 닫기가 불가능하므로 서버에서 잘못된 minVersion을 반환하면 앱 사용 불가 → 서버 측 검증 중요
