# Itto E2E 테스트 체크리스트

## 자동화 테스트 실행 방법
```bash
# UI 통합 테스트 (에뮬레이터 필요)
flutter test integration_test/e2e_test.dart

# API E2E 테스트 (에뮬레이터 필요, 네트워크 접근)
flutter test integration_test/api_e2e_test.dart
```

## 수동 E2E 테스트 시나리오

### 1. 카카오 로그인 (기존 사용자)
- [ ] 앱 시작 → 스플래시 화면 표시 (2초)
- [ ] 로그인 화면 표시 → 카카오/Apple/Google 버튼 3개 확인
- [ ] 카카오 로그인 버튼 탭 → 카카오 인증 페이지 열림
- [ ] 카카오 로그인 완료 → 홈 화면으로 이동
- [ ] 홈 화면에 "Itto" 로고 + "인연 만나기" 토글 표시
- [ ] 탭 4개 (인연/필연/우연/지난인연) 정상 표시

### 2. 회원가입 (신규 사용자)
- [ ] 카카오 로그인 → 회원가입 화면으로 분기
- [ ] Step 1: 위치 서비스 동의 체크 → OS 위치 권한 다이얼로그 표시
- [ ] Step 2: 닉네임 입력 (2~10자 제한)
- [ ] Step 3: 성별 선택 (남/여)
- [ ] Step 4: 생년월일 입력 (만 18세 이상)
- [ ] Step 5: 취미 선택 (서버에서 목록 로드, 3~5개)
- [ ] Step 6: 자기소개 작성 → API 전송 (saveTerms + saveProfile)
- [ ] Step 7: 프로필 사진 업로드 (1~3장)
- [ ] Step 8: 셀카 인증 촬영 → 업로드
- [ ] Step 9: 인증 대기 화면
- [ ] Step 10: "시작하기" 탭 → 홈 화면 이동

### 3. 인연 만나기 (위치 전송)
- [ ] 홈 화면 "인연 만나기" 토글 ON
- [ ] 위치 권한 미승인 시 → 에러 SnackBar 표시
- [ ] 위치 권한 승인 → 토글 활성화 (보라색)
- [ ] 포어그라운드 알림 "인연을 찾고 있습니다" 표시
- [ ] 토글 OFF → 알림 사라짐

### 4. 채팅
- [ ] 인연 탭에서 상대방 카드 확인
- [ ] 채팅방 진입 → 메시지 목록 로드
- [ ] 텍스트 메시지 전송 → 실시간 표시
- [ ] "+" 버튼 → 첨부 메뉴 (사진, 인연 위치 확인)
- [ ] 위치 아이콘 → 만남 위치 지도 화면 이동

### 5. 만남 위치 지도
- [ ] 채팅방 → 위치 아이콘 탭 → 지도 화면 열림
- [ ] 지도에 보라색 마커 표시
- [ ] 하단에 만남 시간 + "약 100m 범위 내 위치" 표시
- [ ] 뒤로 가기 → 채팅방 복귀

### 6. 제외 지역 설정
- [ ] 설정 → 제외 지역 → 지도 화면 열림
- [ ] 현재 위치 중심으로 H3 헥사곤 그리드 표시
- [ ] 셀 탭 → 보라색으로 토글 (선택)
- [ ] 다시 탭 → 회색으로 토글 (해제)
- [ ] 20개 초과 선택 → 에러 SnackBar
- [ ] "저장" → 성공 SnackBar + 이전 화면 복귀
- [ ] "초기화" → 모든 선택 해제

### 7. 설정
- [ ] 프로필 수정 → 닉네임/자기소개 변경 + 저장
- [ ] 프로필 사진 관리 → 사진 추가/삭제
- [ ] 연결 범위 설정 → 슬라이더 변경 + 저장
- [ ] 알림 설정 → 토글 변경 + 저장
- [ ] 로그아웃 → 로그인 화면 이동

### 8. FCM 푸시 알림
- [ ] 로그인 후 FCM 토큰이 백엔드에 등록됨 (디버그 로그 확인)
- [ ] 서버에서 푸시 전송 → 앱에 알림 수신
- [ ] 알림 탭 → 알림 목록 확인
- [ ] 알림 읽음 처리 → 읽음 상태 변경

### 9. 앱 라이프사이클
- [ ] 앱 백그라운드 이동 → 위치 추적 유지
- [ ] 앱 재시작 → 자동 로그인 → 홈 화면 직행
- [ ] 앱 종료 후 재시작 → 토큰 유지 확인
